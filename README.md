# 醒伴 WakeMate

一款结合 Alarmy「任务摩擦」与 AlarmMon「角色化轻游戏」的 iPhone 闹钟。
工程为原生 SwiftUI + AlarmKit，目标设备：你的 iPhone 15 Pro Max（需 iOS 26 或更新）。

> 重要说明：当前工作区是 Windows，无法编译 Swift、无法签名、也无法把 App 装进 iPhone。
> 这里交付的是**完整 Xcode 工程源码 + 云端打包配置 + Windows 侧载步骤**。
> 代码尚未在真机跑过，首次安装请按文末验收清单逐项测试。

## 先用大白话讲清楚三件事

### 1. 为什么不用“必须做题才能关”的闹钟？
那种闹钟本质是一条**手机通知**，可以把它伪装成全屏任务界面，看起来很强制。
但通知有三个毛病：静音键一拨就不响、专注模式会拦、App 被系统杀掉后可能不响。
拿来当每天依赖的闹钟，迟早出事。

### 2. 那这个 App 怎么保证响？
用苹果在 iOS 26 开放的 **AlarmKit**。它跟系统自带“时钟”的闹钟是同一套东西：
静音键挡不住、专注模式挡不住、锁屏也照响，就算你把 App 划掉、手机重启，它照样响。

### 3. 那任务还有什么用？系统闹钟不是有个“停止”按钮吗？
对，系统界面上**一定**有“停止”按钮，苹果不允许 App 把它藏起来。
所以我的做法是：

- 系统闹钟上放两个按钮：**停止** 和 **开始任务**。
- 按“停止”只能关掉当前这一声，我预先排了好几个**备份响铃**（1、3、5、7 分钟后），还会继续响。
- 只有你点“开始任务”并完成数学题/记忆色块/拍照打卡等任务，才会把主响铃和全部备份响铃取消。
- 换句话说：**任务不是“锁住闹钟”，而是“真正结束这一轮闹钟的唯一方式”**。按停止只是把闹钟延后，不是结束。

## 方案 A：免费装到 iPhone（推荐你先用这个）

### 第 0 步：确认系统版本
iPhone → 设置 → 通用 → 关于本机 → iOS 版本。
必须是 **26.0 或更新**。iPhone 15 Pro Max 支持 iOS 26。

### 第 1 步：云端打包成 IPA
IPA 就是苹果的安装包，类似安卓的 APK。打包需要 Mac，但我们借云端 Mac：

1. 把 `WakeMate-GitHub-upload.zip` 解压到电脑上，会得到三项内容：`.github` 文件夹、`WakeMate` 文件夹、`README.md`。
   然后把**这三项全部上传到仓库根目录**（不是只传 WakeMate 文件夹）。
   - 用 GitHub 网页上传时，先在文件资源管理器顶部「查看」勾选「隐藏的项目」，这样能看到 `.github` 文件夹。
   - 把这三项一起拖进 GitHub 的上传框；等页面文件列表里出现 `.github/workflows/build.yml` 才算传对。
   - 如果 `.github` 没传上去，Actions 里找不到打包脚本，先回头补传它。
2. 打开仓库 → Actions → 找到 `Build unsigned IPA` → 点 **Run workflow**。
3. 等几分钟，跑完后在本次运行的页面底部下载 `WakeMate-unsigned-IPA`，解压得到 `WakeMate.ipa`。

（没有 GitHub 账号也可以注册一个，免费。）

### 第 2 步：在 Windows 上装进手机
1. 手机：设置 → 隐私与安全性 → 开发者模式 → 打开（会重启一次）。
2. 电脑：去 Sideloadly 官网下载 Windows 版并安装。
3. 建议专门注册一个**新的 Apple ID** 用来签名，不要用主账号。
4. 数据线连接手机，手机上点“信任此电脑”。
5. 打开 Sideloadly，把 `WakeMate.ipa` 拖进去，填入 Apple ID，点 **Start**。
6. 第一次会要你输入 Apple ID 的“应用专用密码”，在苹果官网账户设置里生成。
7. 装完后回手机：设置 → 通用 → VPN与设备管理 → 点你的 Apple ID → 信任。

### 免费签名的限制（必须知道）
- 证书 **7 天过期**，到期后要重新插线签一次，否则 App 打不开。
- 一个免费 Apple ID 最多同时装 **3 个** 自己签的 App。
- 免费签名没有推送权限，但**这个版本不依赖推送**，不影响闹钟响铃。

### 方案 B：花钱省事
买苹果开发者账号（约 ￥688/年），走 TestFlight 分发：证书一年有效，App 90 天有效，不用每周折腾。如果你后面想长期日常用，这条路更省事。工程里的签名配置留了 `YOURTEAMID` 占位，到时换成你的团队 ID 即可。

## 第一次使用

1. 打开 App → 「闹钟」Tab → 右上角 `+`。
2. 设时间、重复日、角色、任务（默认数学 + 记忆色块；想强制离床就勾上“拍照打卡”）。
3. 点保存时，系统会弹窗问“是否允许醒伴设置闹钟”——**一定要允许**，否则闹钟不会注册。
4. 建议睡前把拍照目标设为卫生间镜子或阳台物件。

## 真机验收清单（请照做）

- [ ] 设一个 3 分钟后的闹钟，打开**静音键**，开启**专注模式**，锁屏，把 App 从后台划掉。
- [ ] 3 分钟后必须全屏响铃，屏幕显示“开始任务”。
- [ ] 点“停止”：1、3、5、7 分钟后备份响铃应继续响。
- [ ] 点“开始任务”：进入任务页，完成全部任务后所有响铃停止。
- [ ] 「记录」Tab 出现一条完成记录，连续天数 +1。
- [ ] 拍照任务能正常调起相机。
- [ ] 杀掉 App、重启手机后再测一次，仍能响。

若第 2 步不响，先检查系统设置里醒伴的闹钟权限是否被关掉，再检查手机系统版本是否 ≥ 26。

## 已知限制（不是 bug，是 iOS 的规则）

1. 系统闹钟的“停止”按钮无法隐藏；我们用备份响铃来降低“按掉就睡回去”的风险，但不能 100% 阻止。
2.  AlarmKit 的自定义声音有长度和格式限制，本版本直接用系统默认铃声，稳定优先。
3. 本版本没有倒计时 Live Activity / 小组件扩展——这是为了减少无 Mac 环境下的打包失败点；闹钟本身不受影响。
4. 拍照任务只验证“拍了一张照片”，不做图像识别；防作弊靠你把目标设在床外。
5. 当前环境无法编译验证，首次构建若遇到 API 签名差异，以 Xcode 26 的报错为准微调；核心调用均按苹果官方示例写法。
